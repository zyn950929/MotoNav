# Android 8.3.21 更新说明

发布日期：2026-10-18。版本号 8.3.21，内部版本号 117。本次公开同步自 8.3.19 以来的 Android 新功能及到达判定修复；iOS 与圆屏固件沿用仓库现有版本。

## 重要修复：导航未结束，小屏提前弹出到达结算

**维护者说明：我认为这是一个比较重大的 bug。** “已到达”画面可能使骑行者误判导航已经结束，因此将本次修复作为重点说明，建议旧版 Android 用户更新。

- 问题现象：用户在 App 8.3.19、圆屏固件 7.8.12 的模拟导航中，距离终点还有约七八百米时，小屏提前出现到达目的地的结算画面，随后又弹回导航界面。
- 原因：高德的“前方终点”提示被当成了真正到达，并向圆屏发送了到达指令；导航结束后的迟到回调也可能重新恢复导航状态。
- 修复：“前方终点”继续作为正常导航，不触发结算。只在当前这一次导航收到真正到达或有效的模拟结束事件后，发送一次到达指令。手动退出、重复结束事件、旧导航回调和结束后的迟到信息不会再次结算或恢复导航。
- 使用变化：临近终点时仍显示导航提示；真正结束后才显示到达结算，无需增加新的操作步骤。

## 新功能一：地图加载状态提示

手机首页及导航页新增地图状态，帮助分辨地图是在准备、传输、等待圆屏确认，还是加载失败。

- 显示等待定位、获取附近地图、传往圆屏的进度、等待圆屏确认和地图就绪等状态。
- 只有收到圆屏对应的地图确认，才显示已就绪；传输进度不等于圆屏已经显示地图。
- 更新下一段地图时提示保留当前底图；加载失败时显示检查网络、地图 Key 与等待重试的提示。
- 状态只反映当前处理进度，不保证网络、地图服务或蓝牙始终可用。此功能是排查提示，不代表所有底图空白问题均已解决。

## 新功能二：骑行轨迹记录与 GPX 导出

在手机首页的“骑行轨迹”区域，点击“查看轨迹 / 记录设置”。

1. “自动记录真实导航和巡航”默认开启，可按需关闭。收到有效定位后，真实导航或巡航会记录轨迹；模拟导航不记录。
2. 在记录列表中查看时间、距离等摘要；点开记录可查看轨迹示意，绿色为起点、橙色为终点，预览不带地图底图。
3. 点击“导出 GPX”，通过系统文件选择器选择保存位置。GPX 使用 WGS84 坐标与 UTC 时间，可交给支持 GPX 的工具查看；不同工具的地图坐标处理可能影响叠加效果。
4. 不需要的记录可在详情中删除，删除前会要求确认。

轨迹保存在手机本机，不由本功能主动上传。记录会过滤重复、过密及明显不可靠的定位，定位中断处会分段，避免跨越缺口直接连线计算距离。程序异常中断后会尝试恢复已写入的记录，但无法补回中断期间没有采集的位置，也不保证系统强制停止后继续记录。

**卸载 App 会清除本机轨迹，重要记录请提前导出。GPX 含有出行位置与时间，分享前请自行检查。**

## 新功能三：常用目的地

1. 搜索并选好目的地后，在路线规划页点击“☆ 收藏到常用目的地”，输入方便识别的名称并保存。
2. 首页目的地区域会显示最多 4 个快捷项，点击即可重新规划路线。
3. 点击“管理常用目的地”查看全部收藏，可规划路线、改名或删除；已收藏地点在路线页也可改名或删除。

最多保存 50 个常用目的地，附近重复地点会合并更新。收藏与最近搜索记录分别保存；它只保存目的地，不是离线地图，也不保证还原之前选中的同一条路线。

## 更新与验证

- 已安装个人编译版的用户，请先备份并沿用 `android/personal.properties` 和整个 `android/keystore` 文件夹，再用新版源码编译，以保留自己的包名和证书。地图、天气仍需配置自己的服务凭据。
- 本次修复在 Titan 2、圆屏固件 7.8.12 的模拟导航中验证，用户确认“这次正常了，到终点才结算”。未以此替代真实道路测试，也未声称重新验证了仓库当前 7.12.0 固件和所有设备组合。
- 到达状态测试覆盖提前终点、重复结束、手动取消、旧会话回调等 45 项；另有地图加载与轨迹采样 34 项、轨迹和收藏持久化 33 项、异常中断恢复 7 项，以及原有巡航、地图风格和区县格式检查。
- 公开源码保留个人包名与签名生成流程，不包含维护者的个人签名、地图/天气 Key、手机日志或真实轨迹。测试入口见 [android/tests/README.md](https://github.com/zyn950929/MotoNav/blob/7c43ad13093878e4249520838bcb975745964725/android/tests/README.md)。
