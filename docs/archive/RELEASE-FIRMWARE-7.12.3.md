# 固件 7.12.3 源码更新

日期：2026-10-21。本次更新源码与构建说明，不新增二进制 Release 或一键烧录 ZIP。不要把历史 7.12.1 的下载包当成 7.12.3。

## 1.75 正式目录

`firmware/boards/175/MotoNav`，固件标识 `v7.12.3`。基于原有 7.12.1 通用固件继续更新，保留 iPhone HID/AMS、逐句歌词、无级旋转和蓝牙关闭防重启修复。

- 配套 Android 四种地图风格：罪恶都市保持；原版独立原色量化，避免圆屏再次加夜间暗角/调色；极简黑白仅显示道路网和导航线；龙珠雷达保持。
- 识别新的主题附加参数（例如 `#t,主题,1`），切换风格清理旧图状态；保留旧 `#t,主题` 与既有地图/路线包解析。
- 合入 7.12.2 的外接电源判断：读取 AXP2101 VBUS-good，而不是用“正在充电”代替“插电”。插 USB/外部电源时不因五分钟空闲而关机，满电或无电池时也按供电状态处理。
- 拔电后重新计满五分钟；导航/巡航期间不触发空闲关机，操作交互会重置计时。天气、音乐、普通心跳不视为导航活动。手动 PWR 关机不变。
- 状态轮询约 500 ms，到关机边界强制刷新；I2C 失败或供电状态不明时保持开机，避免误关机。保留五分钟关机后立即重启问题的修复。

固件保留 iOS 0.13.8 使用的导航、地图、HID/AMS、歌词与旋转协议，也继续接收旧主题命令。**本次不修改 iOS 源码、IPA 或发布流程**；iOS 仍使用自己的界面、地图处理和既有主题行为，不因固件更新获得 Android 五页面、网页摩托车入口或四种新处理流程。源码协议兼容不等于本次已完成两端交替连接、所有主题及实路验证。

## 构建

安装 Arduino CLI、Espressif ESP32 Core 3.3.10，使用仓库内 `firmware/libraries`。ESP32-S3、16MB Flash、OPI PSRAM、CDC 开启、`app3M_fat9M_16MB` 分区。

```powershell
.\firmware\build.ps1 -Board 175
# 1.85B 实验配置，PanelVariant 可为 0、1、2：
.\firmware\build.ps1 -Board 185b -PanelVariant 0
```

Mac/Linux 的现有 `python3 firmware/build.py` 入口仅构建 1.75。可通过命令参数指定 Arduino CLI/配置文件。输出在 `firmware/dist/<板型>/panel<编号>`；同板同分区升级用 `app_0x10000`，首次安装用 `full_0x0`，完整刷写可能影响原设置。构建生成 SHA-256 清单，核验板型、版本和偏移后再烧录。
