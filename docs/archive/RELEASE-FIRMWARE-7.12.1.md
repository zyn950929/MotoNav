# MotoNav 圆屏固件 7.12.1

发布日期：2026-10-18。适用微雪 ESP32-S3-Touch-AMOLED-1.75（466×466、16 MB Flash、8 MB OPI PSRAM）。

## 重要关机修复

旧的本地 7.8.12 在没有导航五分钟后，会在关闭蓝牙时先释放服务对象；迟到的断连事件继续访问已释放的连接数据，触发 `LoadProhibited` 崩溃并自动重启，导致自动关机失效。原版串口复现及回溯已定位到 `BLEServer::removePeerDevice`。这是一项影响自动关机可靠性的重要修复，建议相关用户升级。

7.12.1 以 GitHub 7.12.0 为基础，合入已修复的本地 7.8.13：关机前不销毁仍可能收到回调的蓝牙对象；优先通过 AXP2101 断电，失败时停止蓝牙主机与控制器后进入深度睡眠。休眠回退要求 BOOT 稳定释放后才启用唤醒，避免按键低电平立即唤醒。

## 融合后保留与新增的功能

- 保留 7.12.0 的 iOS HID 媒体按键、AMS 歌曲和播放状态、可选歌词、歌词关闭清理及歌手栏刷新、HID 未就绪时的 AMS 备用控制。
- 保留安卓 `#D角度`、iOS `#R,四档,精确角度` 及旧四档旋转兼容。
- 保留现有导航、地图与建筑、天气、开机品牌、巡航和到达动画协议。
- 新增五分钟无导航自动关机。导航或巡航中不关机；结束导航、到达或断连后按空闲规则计时。配对、来电、触摸和滑动保护当前使用；空闲心跳、天气、音乐及 HID/AMS 更新不阻止关机。

## 安卓与 iOS 兼容范围

已对照 Android 8.3.21 公开源码/分享一键打包版与 iOS 0.13.8，核对 BLE UUID、导航和真实到达、地图分片与确认、文字图片、建筑能力、天气、旋转和音乐模式命令，可共用同一份固件。切换手机需先断开前一部手机，再按 App 和系统提示配对。

旧个人直装 Android 8.3.21 构建缺少收到 `CAP,HID,1` 后发送 `#HM,0` 的处理：导航、地图、天气及到达协议兼容，但圆屏先在 iPhone 保存 HID 音乐模式后，切回该构建时音乐模式可能未复位。仓库安卓公开源码及最新 8.3.21 分享包已包含此处理；相同版本号不代表所有历史构建内容完全一致。

固件升级不会给旧版 App 补上提前到达的手机端修复。请搭配 Android 8.3.21 或 iOS 0.13.8 及其后续对应版本。
