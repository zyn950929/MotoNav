## 网页摩托车路线：使用方法

1. 配好自己的高德 Android SDK Key，按需要授予定位、蓝牙和前台服务权限；在圆屏设置连接设备。
2. 首页进入“网页摩托车规划（实验）”，在高德网页选择摩托车、设置起点、终点及途经点。也可粘贴 `https://www.amap.com/ssr/dir?...&type=4` 的完整路线链接。
3. 等网页规划完成，再读取路线。程序从链接提取起终点及可解析的途经点，通过网页当前使用的摩托车算路接口取得完整折线与转向步骤。
4. 在 MotoNav 原生方案列表重新选择路线，再开始模拟或真实导航。网页里高亮的方案不会自动同步为原生列表的当前方案。
5. 导航页采用与驾车页一致的地图、转向卡片、悬浮车速及底部按钮布局；支持全览/跟随、静音、返回规划与退出。模拟可暂停，速度可切换 60/120/180 km/h。

该入口不会把摩托车路线转换为普通驾车 SDK 算路；普通搜索/驾车入口保持各自逻辑。收到网页验证页、错误码、空路线或异常坐标时显示失败，不伪造路线。

## 声音、走错路和到达判定

语音由手机上的 Android TTS 引擎合成，沿用“导航语音”设置，不是网页提供的高德语音包。播报依据网页返回的转向步骤，预计剩余时间按剩余路程估算。

真实导航使用高德定位和本地路线跟踪。偏离超过 `max(55 米, 定位精度×1.5)`，连续三次有效定位后请求重算；两次重算至少间隔 30 秒。重算以当前定位为起点，保留终点和尚未经过的途经点，仍用网页摩托车接口。失败保留原路线并允许后续重试，不退回普通驾车路线。它不具备官方导航 SDK 完整的复杂路口匹配能力。

继续保留 8.3.21 的“前方终点不等于到达”修复；维护者认为旧版提前结算是一个比较重大的 bug。网页导航另外要求沿线剩余与终点直线距离均不超过约 30 米、定位精度不差于 25 米，并连续三次、持续至少两秒满足条件；对起步靠近终点和环线路线做保护。手动退出与重复回调不触发重复到达动画。

## 地图来源与四种风格

Android 的普通底图、卫星与沿线离线地图均改为高德 SDK；删除天地图取图实现与 OSM 调用，旧天地图设置仅保留清理迁移，不再用于请求。和风天气继续独立配置。

| 风格 | 处理 |
| --- | --- |
| 罪恶都市 | 保留原有效果 |
| 原版 | 高德 SDK 初始地图截图，独立取色；圆屏采用 16 色量化，无法与手机全彩图逐像素一致 |
| 极简黑白 | 独立提取道路网；黑底、灰白道路及导航线，去掉建筑、绿地、水面和文字 |
| 龙珠雷达 | 原有效果：绿底、十字网格、导航路线与四星球目的地，不取底图 |

四种风格各自处理，没有在罪恶都市成图上再套滤镜。完整匹配原版/极简黑白的圆屏显示建议搭配固件 7.12.3；旧固件仍可连接，但可能对地图再次调色。

保留此前新增的地图加载状态、常用目的地、骑行轨迹与 GPX 导出、驾车/自行车分享、十分钟静止退出巡航和到达修复。电瓶车分享不列入支持范围；历史高德分享链接仍受服务端还原能力影响。

## 登录与能力限制

WebView 开启 Cookie 接收与 DOM storage，代码不主动清除登录数据；由应用沙箱/WebView 保存。当前没有额外强制 Cookie flush，未完成跨重启登录持久化验证，不能承诺一次登录永久有效。更换包名、清除数据或网站会话到期仍可能需要重新登录。原生路线 HTTP 请求没有自动把 WebView Cookie 注入请求；网页登录不等于给所有原生请求提供认证。

当前依赖网页的内部服务 `https://amap-pc-ssr.amap.com/ssr/api/getMotorRoutePlan`，不属于承诺稳定的公开摩托车导航 SDK 接口；可能因接口调整、风控、登录、验证或服务权限而失效，不尝试绕过访问限制。仍需按高德规则使用数据和 SDK。

程序没有提交车牌、排量等车辆限制条件，不保证覆盖各地禁摩规则；网页返回摩托车路线也不等于验证全程合法。没有车道级引导、电子眼、限速牌与红绿灯秒数。请以现场交通标志和法规为准。

## 编译、更新与配置

推荐使用仓库根目录“一键打包.bat”，或在 Android Studio 打开 `android/`。环境为 JDK 17/21、Gradle 8.10.2、Android SDK 35；不要让 Gradle 8.10.2 使用 JDK 25。当前构建仅包含 arm64-v8a，最低 Android 8。

一键脚本为每位使用者生成自己的 applicationId 和签名证书；高德 Key 需绑定该包名及发布 SHA1。在 App 的“地图 Key”页可查看并配置，修改 Key 后按提示重启。源代码内没有可共用的地图凭据。

更新已自行编译的版本前，备份并复制回 `android/personal.properties` 与整个 `android/keystore/`，然后编译，才能覆盖安装并保留原有配置。直接编译 `com.example.motonav` 的 APK 与维护者个人包不能互相覆盖。不要公开上传生成的证书、密码、Cookie、轨迹或个人配置。
