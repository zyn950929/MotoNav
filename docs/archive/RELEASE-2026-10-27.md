# 2026-10-27 安卓双版本整理与 1.75 固件更新

- `android/standard/`：普通版 8.3.26，沿用原独立 App，未加入读秒组件。原来的根目录 `android/app` 已整体移入这里，构建入口同步调整。
- `android/countdown/`：读秒版 8.3.26-single.30，自主源码、单引擎路径读取代码、指定输入的最小集成增量与完整构建工具。
- `experiments/traffic-lights/README.md`：旧链接迁移指引，避免留下第三套过时源码；历史实现保留在 Git 历史中。
- `firmware/boards/175/MotoNav/`：最新 1.75 通用固件 7.12.10-pages.4。`firmware/libraries/MotoNavIpcStackGuard/` 必须与源码一并保留。
- `ios/`、iOS 工作流与根目录 `RELEASE_VERSION` 沿用原状，本轮不构建或发布 IPA。

## 普通版 8.3.26

保留已公开 8.3.26 的原有逻辑，不把读秒版依赖引入普通版。仅将源码移入独立工程，并补入 `#TIME` 手机时钟同步：认证连接后发送当下时间与手机时区，后续每分钟校准，检测手动改时和时区变化；不缓存旧校时包，不增加新的导航引擎。

根目录 `一键打包.bat` 继续默认构建普通版，新入口 `一键打包-普通版.bat` 同样有效。Android Studio 打开 `android/standard`；Gradle JVM 使用兼容的 JDK 17/21。成品 `output/MotoNav-personal.apk`，包名与证书 SHA1 在同目录 `Application-info.txt`。详细工具参数与私钥保存方法见工程 README。

## 读秒版 single.30：网页摩托车后台导航启动修复

修复网页摩托车路线已规划、后台却未真正开始导航时没有红绿灯读秒的问题。原先发送启动指令后依赖引导回调判断成功，缺少对实际运行状态的核实；本次改为明确启动所选路线，并连续确认后台真实导航状态，旧会话和过期状态不能作为启动成功凭据。未成功时有限重试；运行中的后台导航持续停止时最多恢复两次，不因正常停车、暂时没有引导回调或失去状态心跳而反复重启。用户主动结束导航后撤销监测。

原故障触发条件本轮未稳定复现；已经验证普通启动、锁屏启动、后台实际停止后的恢复、主动结束后的清理，并收到真实灯色和秒数。后续仍需实车验证，不把启动修复当作所有路口都有数据的保证。本次不修改普通版、iOS 或固件。

### 保留 single.29 的已有功能

此次更新到当前设备使用的版本，包含普通驾车多路线选择、三档模拟速度、网页摩托车规划、自行车与分享入口；摩托车和驾车均可手动设置最多三个途经点、搜索具体加油站并重新规划。支持替换、排序、删除和取消；网页历史保存途经点顺序并按有序坐标去重。收藏、历史重选、导航中返回设置与锁屏恢复处理保留。

此前网页自动选出的后台约束点有时紧靠路口，原生引擎先提示到达途经点，下一道路与网页转弯不一致，导致严格路口核对不显示灯数据。本次只把自动生成的约束点适当移到转弯之后的原线路上，用户手动途经点不移动；仍保留位置、方向、路口身份与时效核对。不会用直行数据冒充缺少的左转秒数。

完整 APK 使用指定兼容数据组件；根目录 `Build-Countdown.ps1`／一键打包入口会自动从本仓库 Release 下载 `provider.apk`，校验大小和 SHA256 后复用本地缓存，无需新手另找文件。Git 目录只包含自主源码、构建工具、校验信息与最小增量，不包含原始第三方 APK、完整反编译目录或个人 Key/证书。单独 Gradle 生成的中间包不能替代最终包。构建会沿用本机已有签名，首次在本机生成新签名，并输出固定最终包名 `com.autonavi.amapauto` 和实际证书 SHA1；用它们申请本人的高德 Android Key。

**安卓红绿灯读秒不保证一直有效**，也不保证全路口／全方向覆盖。账号、权限、定位、网络、后台策略、接口及上游数据变化均可能影响显示；缺数不捏造。

## 固件 7.12.10-pages.4

固定音乐／导航首页／天气位置，主页显示大号 24 小时时间和小号日期，保留骑手动画。只在显示内容变化时重画时钟，减少重复计算；完全关机后等待手机校时。公开版使用原通用 MotoNav／品牌动画，不带个人 Rebel500 图片。

已定位实际开机反复重启为蓝牙初始化时的系统 IPC 任务栈越界，原栈只有 1KB；为匹配的两个系统任务各保底 4KB，新增约 6KB 动态内存。没有关闭看门狗，其他任务参数、优先级、地图、灯卡和五分钟关机处理不改。构建脚本显式加入链接设置，漏掉设置会构建失败而不是悄悄省略修复。

新固件和两种安卓共用既有导航协议。1.85B 仍是原 7.12.3-185B，没有升级或新二进制；不可混刷。iOS 源码与工作流不改，本轮没有新 iPhone 测试或时钟功能适配。
