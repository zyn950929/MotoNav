## Android 原版 8.3.26

- 原生摩托车规划：在 App 输入起点、目的地及途经点，后台读取网页摩托车方案，预览并选择路线；正常规划无需进入网页。登录／验证时仍需用户完成，Cookie 保存于本机。
- 新增自行车目的地规划，使用 SDK 骑行接口，不将自行车请求转换为驾车；仍不加入电瓶车规划／分享。
- 改进蓝牙接续系统已有连接、服务发现、通知订阅、MTU 协商、超时重试与旧连接回调隔离，解决部分“系统已连但 App 一直连接中”。
- 保留五页面、靠前的巡航入口、四种独立地图风格、地图加载状态、轨迹／GPX、收藏、区级天气、到达误触发修复。
- 该原版不包含实验版专用的红绿灯读秒功能。普通入口一键打包仍构建 `android/`。

## Android 红绿灯读秒实验

在原版基础上另行迭代：

- 真实红绿灯数据通过接收、路口核对、时效控制及 BLE 发到圆屏。前方约 300 米内显示右侧左转／直行／右转竖排图标与数字；不存在的数据不会编造秒数。
- 缺少右转数据使用灰色方向图标／灰色实心圆，无读秒，避免绿色被误认为已确认放行。
- 改进灯快照切换、BLE 写入延迟、过期数据处理及圆屏灯卡片闪烁；仍需更多实际道路验证，不承诺任何场景完全不闪。
- 导航中可收起导航画面回到五个页面修改设置，再返回正在运行的导航；主动结束导航才退出导航会话。
- 处理重复导航语音，避免两套播报同时出声。
- 网页摩托车路线增加沿途关键点与路口信息核对；按道路、方向与位置匹配后才采用灯数据，不承诺所有路口都能正确匹配。
- 补回网页导航信号灯地图标记、电子眼／测速／拍照点位。覆盖由上游数据和匹配结果决定，不等于完整道路限速或车道数据。

**安卓红绿灯读秒不保证一直有效。** 它依赖可能变化的上游数据及运行环境，不能承诺永久有效、离线可用、所有城市／路口覆盖、所有方向同时有数或长期后台稳定运行。上游调整、登录失效、网络或定位问题、系统省电、道路／路线不一致都可能导致停更、隐藏或失效。巡航无路线读秒尚未完成实际道路确认。

测试中的真实倒计时来源是上游返回，不是自行生成的演示数值；虚拟定位回放不代表完成真实道路测试。室内 SDK 模拟与实际定位的数据来源可能不同，不能把真实位置的灯套到另一条模拟路线上。

[实验版构建、输入依赖及第三方说明](https://github.com/zyn950929/MotoNav/blob/a28b7aaa5989eb3bc1fb3b865bacf81cbafeda70/experiments/traffic-lights/README.md)。

## iOS 0.15.0

[完整 iOS 说明](RELEASE-IOS-0.15.0.md) 中逐项列出实现、构建及限制。主要包括：

- 原生摩托车起终点／最多三途经点、多方案预览与选择、持久登录会话。
- 自行车 SDK 规划、真实／模拟导航和偏航重算。
- 导航中返回设置、恢复导航入口和独立导航界面。
- 网页电子眼静态元数据匹配，不额外启动一套驾车导航／语音。
- 蓝牙连接恢复、异常定位／路线跳点保护、终点多次确认及到达误触发修复。
- 自动优选系统可用的普通话音色：Premium → 增强 → 默认；手动音色优先。下载音色后，下次自动播报重新检查。iOS 15 保持增强／默认回退。

**iOS 不包含红绿灯灯色和读秒。** 系统后台 GPU 取图、音乐／电话及权限能力与 Android 不同，不宣称完全相同。Windows 只完成 Swift 语法和工程静态检查；需在 Mac 使用 `bash scripts/build-ios-local.sh` 执行回归及 arm64 编译，成功才产生 0.15.0 IPA。现有发布自动化保留原版本，不会因本轮源码提交自动发布一个未经验证的新 IPA。

## 1.75 固件

- 主文件按职责拆出图标资源、绘图、地图、页面、通信等，便于维护。
- 精确计算缓存及绘制优化；此前用户确认罪恶都市、极简黑白均正常。属于小幅优化，不作为固定帧率保证。
- 车道提醒跟随转弯倒计时开始显示，仅在 App 提供车道数据时绘制。
- 右侧竖排灯卡片、有效期与失效回退；普通 Android 与 iOS 无灯包时仍走原导航协议。
- 网页导航转弯环改为按收到距离包的时间间隔连续过渡，重复包不重新启动过渡；换方向、距离跳变或断更时重置。不预测车辆位置，不增加 BLE 流量。
- 保留旋转记忆、音乐 HID／AMS、歌词和 1.75 外接电源不自动关机／纯电池无导航五分钟关机。
- 公开版恢复通用 MotoNav／品牌动画，不包含维护者个人 Rebel 500 图片。此次没有刷写维护者正在使用的个人设备。
