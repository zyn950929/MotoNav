# 安卓读秒版 8.3.26-single.31：省电优化

更新日期：2026-10-29。本次更新 `android/countdown` 的读秒版源码、版本号和完整构建入口。普通版仍为 8.3.26，iOS 与圆屏固件未改。

## 最终行为

1. **蓝牙搜索减少持续高功耗扫描**：初期使用均衡扫描，连续搜索失败后使用低功耗扫描；重试等待逐步增至 5／15／30／60 秒。回到首页后恢复待重试的搜索，认证成功后重置退避，失败的连接尝试不会反复清空计数。
2. **CPU 唤醒锁按需持有**：导航与巡航期间保留后台运行能力；选路、到达和待机状态释放不必要的唤醒锁。每 30 秒核对状态，在长途导航中提前续期，服务销毁后撤销检查。
3. **独立 GPS 观察降频**：从 1000ms 调整为 2000ms，位移门槛保留为 0 米。原 PR 的 2 米门槛没有直接沿用，以便停车等灯时仍能刷新定位与有效期；不会为省电而停掉导航引擎自身的定位。
4. **地图与车标显示**：保留原 PR 的平滑镜头移动和风格预览修正；按跟随／非跟随模式处理车标方向，切换模式时也更新方向。

本次不更改小屏通信协议、红绿灯包格式或固件。读秒仍属于实验能力，数据覆盖和持续可用性不保证，必须以现场交通信号为准。

## 打包与升级

继续使用根目录 `一键打包-读秒版.bat`、`Build-Countdown.ps1` 或 `android/countdown/build-countdown.py`。脚本自动获取并校验已固定的 `provider.apk`，最终成品为 `android/countdown/output/MotoNav-8.3.26-single.31-countdown.apk`；仅运行 Gradle 得到的中间 APK 不能独立替代完整成品。

WorkBuddy 提示词已更新到 single.31，使用方法见 [读秒版说明](../../android/countdown/README.md)。公开完整构建保持原有包名与签名生成流程；已有用户请沿用自己的包名、签名和匹配的高德 Key。此次为维护者单独生成的新包名发布签名包、签名私钥及个人凭据不上传源码仓库，也不改变其他用户的升级身份。
