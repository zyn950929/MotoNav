# 1.75 固件 7.12.10-pages.4：开机稳定性、固定页面与时钟

只适用于微雪 ESP32-S3-Touch-AMOLED-1.75（466×466）。不能刷入 1.85B 或 M5Stack。安卓两版共用；本轮不改 iOS。

## 更新内容

1. 修复蓝牙初始化时的系统 IPC 任务栈越界。真实崩溃转储已校验 CRC、与对应固件 ELF 的 SHA256 匹配，异常栈指针低于栈底。两个匹配任务各由 1024 字节保底为 4096 字节，总计增加约 6KB 动态内存；其他任务、优先级、核心、看门狗和关机逻辑不改。
2. 固定页面：音乐在左、首页／导航居中、天气在右，降雨在天气上方、预警在下方；按既定方向切换，不来回循环。
3. 首页大号 `HH:mm` 24小时时间，小号 `yyyy-MM-dd` 日期。安卓普通版和读秒版均包含校时支持；断连后继续走时，完全关机后等待手机校时，未同步时显示占位。iOS 本轮没有新增校时支持。
4. 保留连续转弯环、车道同步提醒、四风格、读秒卡片协议、旋转记忆、HID/AMS 音乐及歌词、电池五分钟无导航关机和插电不自动关机。
5. **公开版使用通用 MotoNav／品牌开机动画，不含个人 Rebel500 图片。**

## 下载和烧录

从本轮 Release 下载 `MotoNav-1.75-v7.12.10-pages.4-Universal-Flasher.zip`，完整解压到普通文件夹，双击 `一键烧录.bat`。不要直接在 ZIP 中运行。

- 已有同板型、16MB / app3M_fat9M_16MB 分区的 MotoNav：选择默认的应用升级，写入 `0x10000`，保留设置与配对。
- 首次安装、其他分区或救砖：完整刷写会整片擦除，清空原程序、配对和设置；按提示核对板型并先备份。
- 如果没有串口，检查数据线；必要时按住 BOOT 再复位进入下载模式。工具会先校验文件大小、SHA256、板型与镜像格式，失败时停止。
- `校验文件.bat` 只检查文件，不访问圆屏。已有烧录工具也可使用 Release 中独立的应用镜像和完整镜像，无需重新下载工具。

## 源码构建

`firmware/build.ps1 -Board 175` 或 `python firmware/build.py`，使用 ESP32 Arduino Core 3.3.10 和 OPI PSRAM 配置。必须保留 `firmware/libraries/MotoNavIpcStackGuard`，脚本会显式传入 `-Wl,--wrap=xTaskCreatePinnedToCore`。输出在 `firmware/dist/175/panel0`。

`firmware/package_flasher.py --tools-dir <包含esptool.exe和许可的目录>` 可从已编译镜像重新生成独立包，不连接硬件。新构建不能自动继承别人的硬件测试结论；可选验证记录必须与该镜像 SHA256 一致。

## 验证范围

共享修复在个人开机画面版上进行了 8 次手机蓝牙断开的受控重启，每次一次启动成功；两个任务各有约 3KB 剩余栈。刷前刷后 NVS 逐字节相同。用户按约两分钟关机静置、手机蓝牙断开、纯电池开机流程确认“一次开机正常，未再重启”。时长未仪器计时，更长时间久置仍需日常观察。

公开版更换通用动画后重新编译，完成镜像、链接入口、资源和打包检查；为保留用户设备上的个人画面，**公开二进制没有再次覆盖刷入实物**。具体验证以本轮记录为准，不承诺温度、续航或导航帧率提升。未进行新的 iPhone 连接／道路测试。
