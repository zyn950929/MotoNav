# MotoNav iOS 0.13.8

本版仅修复提前触发到达动画及相关导航结束回调问题，继续使用通用圆屏固件 7.12.0，无需因本次修复重新刷写圆屏。Android 8.3.21 及其他已有功能保持不变。

## 较重大 bug：未到终点却提前播放到达动画

**维护者说明：我认为这是一个比较重大的 bug。** 旧版将高德“前方终点”图标直接转换为圆屏到达指令，距离终点仍有一段路、甚至数百米时，就可能播放到达动画，随后又被新的导航信息覆盖，容易误导使用者。建议旧版 iOS 用户更新。

- “前方终点”继续作为普通导航处理，并提示“前方为目的地”，不会因剩余距离推算到零就结算。
- 只有本次导航收到真正到达事件，或本次模拟导航收到有效结束事件，才发送一次到达指令。
- 手动退出先关闭回调入口，再停止 SDK，避免退出模拟导航被当成正常到达。
- 重复结束、已结束会话的导航更新和旧代理回调会被忽略；旧的四秒到达清理计时不会停止新导航或巡航。
- SDK 回调经带有会话编号的代理转到主线程处理，避免已排队的旧消息覆盖当前状态。

## 安装

下载本 Release 的 `MotoNav-0.13.8-unsigned.ipa`，使用自己的 Apple 账号通过 Sideloadly 签名安装。沿用原先的签名账号与 Bundle ID，并先备份重要设置；高德 Key 应绑定安装后手机上显示的实际 Bundle ID。详细步骤见 [安装与续签说明](INSTALL-IOS.md)。

IPA 由 GitHub 的 macOS 构建流程生成，只有回归检查、无签名 Release 编译及流程后续检查成功后才发布。源码中新增到达生命周期和会话回调测试，运行方式见 [iOS 工程说明](../../ios/README.md)。

本次尚未完成 iPhone 自签安装、圆屏联动和道路实测。自动检查不能替代真机验证；请先在安全静止环境中检查临近终点、真正到达、手动退出、重新开始导航以及巡航切换。
