# MotoNav iOS 0.15.0 · 安卓功能对齐源码

以 2026-10-25 安卓端的非读秒功能为基准，在 iOS 0.14.0 上独立更新。由 AI 开发；本次源码已同步至 GitHub，Fresh 不包含在本轮更新中。

**这是源码交付，尚未用 Xcode 编译、生成新版 IPA 或在 iPhone 上实测。** Windows 端已检查 Swift 语法、工程文件引用、版本号、依赖锁定及交付文件完整性。源码内的 Mac 回归测试已补充，执行结果仍待 Mac 验证。此前 0.14.0 的 IPA 保留原名，不能代表本次源码。

## 本轮新增和补齐

| 功能 | iOS 0.15.0 的实现 |
| --- | --- |
| 摩托车原生规划 | 首页进入“摩托车路线规划”，选择当前位置或搜索起点、目的地，最多三个途经点；直接请求摩托车网页服务，在 App 中预览、选择多个方案，再开始真实或模拟导航 |
| 登录保存 | 正常规划不展示网页；遇到登录或验证要求，打开“高德登录／验证”。使用本机持久 WK Cookie，查询结果中的有效会话 Cookie 回存；过期仍需本人重新登录 |
| 自行车直接规划 | 首页“自行车路线规划”；使用高德 iOS 搜索 SDK 的自行车接口，支持当前位置／指定起点、目的地、地图预览、路线选择、真实／模拟跟随及偏航重算。无需 Web 服务 Key，不支持电瓶车及自行车途经点 |
| 导航中改设置 | 普通 SDK 导航点“设置”，网页／自行车导航点“返回设置”；只收起导航画面。首页五个页面仍能修改设置，顶部持续显示“导航继续运行中”，点“回到导航”恢复画面。不会因为收起界面主动停止语音、定位或圆屏传输 |
| 导航画面 | 网页／自行车独立导航改为地图背景、顶部转向卡片、底部速度／剩余信息和操作卡片，支持昼夜、全览／跟随、静音、模拟暂停和调速 |
| 网页电子眼 | 另外向 iOS 导航 SDK 查询静态路线元数据，提取摄像头；以所选网页原路线的道路名、距离和进路口方向核对。通过的前方一公里点位经现有协议送到圆屏；提供了限速值才显示测速提醒。只做静态查询，不启动驾车导航、不替换摩托车路线、不另播一套声音 |
| 电子眼生命周期 | 换路线、偏航重算或退出后旧结果作废；匹配在后台执行；定位不新鲜时清理点位；重回原路线可以恢复查询 |
| 蓝牙恢复 | 优先接续系统已有的圆屏连接；避免连接中又扫描覆盖；读取服务／通知订阅增加超时重试和稍后自动重试；过滤旧外设及旧通知对象回调，保留配对信息 |
| 网页定位及到达 | 限制单次路线进度推进、过滤异常跳点及重复定位、绕圈起点不跳到终点；到达需路线进度、终点物理距离、精度及持续多次定位共同确认；到达前不先发清屏命令 |
| 模拟稳定性 | 按实际经过时间推进，暂停期间不积攒位移；速度仍为 60／120／180 km/h；模拟不记录真实骑行轨迹 |
| 路线处理 | 累积里程和路线坐标缓存，减少导航更新时重复遍历；改路线使旧算路回调和静态元数据失效 |
| 中文播报音质 | “自动优选中文”枚举系统当前可用的 zh-CN 音色，优先 Premium（iOS 16 起），其次增强语音，最后回退系统默认普通话；用户手动选定的有效音色优先，每次自动播报前重新检查可用音色 |

本轮**不包含红绿灯灯色和读秒功能**。保留原有 SDK 已经提供的普通路口位置、数量和距离提示。

## 继续保留的已有功能

- 首页搜索、圆屏显示、导航语音、圆屏设置、地图 Key 五页面，巡航入口靠前。
- 普通驾车多路线导航、模拟导航、途经点、原路线分享导入；自行车分享导入，电瓶车分享继续不支持。
- 罪恶都市、原版高德、极简黑白、龙珠雷达四种独立风格，按风格分离缓存；仅使用高德地图。
- 地图加载／传输状态、沿线地图准备、蓝牙地图重传、圆屏楼块能力探测。
- 骑行轨迹记录、GPX 导出、常用目的地、最近目的地。
- 区级天气、和风天气详情、自行填写地图／天气 Key。
- 系统中文语音、音色、语速、音调、静音、试听及播报压低音乐。
- 圆屏品牌开机、亮度、昼夜、旋转记忆、进度环、预判、HID／AMS 音乐和歌词。
- 巡航静止十分钟自动退出、SDK 会话门控及提前到达动画修复。

### 下载更自然的中文播报音色

在 iPhone 的“设置 → 辅助功能 → 朗读内容（部分系统称‘朗读与语音’）→ 声音 → 中文”中下载普通话增强／Premium 音色，下载完成后，在 MotoNav“导航语音 → 系统音色”保留“自动优选中文”即可。App 不会替你下载音色，只能选择系统当前提供的可用音色；具体名称和可下载项目随 iOS 版本变化。之前手动选过音色的用户，切回“自动优选中文”后才启用自动优选。已选音色不可用时也会自动回退，不会清除保存的选择。

此项仍待 iPhone 验证实际音色与下载后的刷新行为。实现依据：[Apple 语音音质枚举](https://developer.apple.com/documentation/avfaudio/avspeechsynthesisvoicequality)。

## 验证边界和平台差异

- 新版未做 Xcode 类型检查／链接，也未在 iPhone 上验证 Key、权限、登录、BLE、背景运行和道路效果。不能只凭 Windows 语法解析认定已可安装运行。
- 高德网页服务并非稳定公开 SDK，可能要求登录、验证或改变返回结构；不承诺自动规避所有禁摩路段。失败会提示，不回退为驾车路线。
- 摄像头覆盖取决于 SDK。平行道路、重复经过、路名不明、方向不符或偏差超限时丢弃，不保证所有点位；不提供完整道路通用限速。自行车规划不查询驾车电子眼。
- 元数据查询使用最多三个参考关键点，并不能保证参考驾车路径与摩托车路径一致，所以每个点仍需单独匹配。摄像头值未提供时不编造限速。
- iOS 后台不能持续执行地图 SDK 的 GPU 截图。出发前在前台准备沿线底图，锁屏继续定位／语音／BLE 时优先使用已准备的地图；不承诺锁屏后无限取新图。
- 系统音色、第三方音乐／来电权限等仍受 iOS 平台约束。iOS 不移植 Android TTS 引擎选择、读取别的 App 播放会话或接听电话功能。
- 最近的转弯环连续填充改动在 1.75 固件 7.12.9-junction.11 中完成，无新增协议；iOS 继续发送原有距离指令。1.85B 等旧固件保留其自身的显示行为。

## 在 Mac 编译

安装并启动过 Xcode，准备 CocoaPods 1.16.2、Python 3。在仓库根目录终端执行：

```sh
bash scripts/build-ios-local.sh
```

脚本使用 Podfile.lock 的原依赖（AMapNavi 10.1.600／AMapSearch 9.7.5），先运行核心回归测试，再进行 iPhone arm64 Release 编译；成功后才生成 `output/MotoNav-0.15.0-unsigned.ipa`。它不会上传代码、登录 Apple 账号、签名、推送 GitHub 或发布应用。

也可在 `ios` 目录执行 `pod install --deployment`，用 Xcode 打开 `MotoNav.xcworkspace`。分享扩展需一并编译。个人签名安装时，用**实际签名后的主应用 Bundle ID**申请高德 iOS Key，不使用 Android 的 SHA1；默认示例 ID 是 `com.example.motonav`，扩展为主 ID 加 `.share`。

源码不含 Apple 证书、描述文件、私人签名或地图 Key。0.14.0 文件夹和旧 IPA 未改；不要把旧 IPA 重命名成 0.15.0。

接口依据：[高德 iOS 自行车规划](https://developer.amap.com/api/ios-sdk/guide/route-plan/ride)、[AMapNaviRoute 元数据](https://a.amap.com/lbs/static/unzip/iOS_Navi_Doc/interface_a_map_navi_route.html)。
