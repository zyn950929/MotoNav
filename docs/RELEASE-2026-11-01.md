## 安卓读秒版

五栏精简 UI、统一卡片和选路布局；不包含四栏目界面改造；保留摩托车网页 / 驾车 / 自行车、60 / 100 / 120 模拟、途经点 / 加油站、收藏 / 历史、后台导航和停车读秒处理。

源码与维护者指定的 single.32-fresh.1 正式 APK 对应，保持五栏精简 UI，不使用四栏目适配或 phone 联动实验版。保留 single.32 已包含的 nongxl PR #9 省电贡献与兼容修正；本次不承诺节电比例。读秒端后续 BLE v2 / Deflate / XOR / 专辑封面与路口图片通道不在此版本。

普通版源码保持整理前主分支的同一目录树；不对普通版做 UI 或功能回退。既有 PR 与提交历史保留，不重写仓库历史。

完整构建自动下载并核对额外组件，最终输出完整 APK。包名固定 `com.motonav.app.fresh`，用实际签名 SHA1 申请自己的高德 Android Key。安卓下载页只提供对应源码，不上传预签名 APK、私人签名或维护者的证书 SHA1。

## 固件和 IPA

pages.5 保留固定页面、时间 / 日期、启动栈修正和 iOS 楼块接续；Windows / Mac 包镜像逐字节一致，公开开机不含个人 Rebel500。后续地图压缩实验未保留。1.85B 沿用 7.12.3-185B，不提供混刷镜像。

Mac 包包含 Apple 芯片 / Intel 原生工具。默认应用升级保留设置，完整安装需确认且会清空设置。

IPA 为已构建的 iOS 0.16.0 Build12 未签名包，含分享扩展。源自原 Build12 工作流，未因安卓整理改变 iOS 功能。以本人 Apple 账号签名安装，申请 Key 时使用最终 Bundle ID；不含读秒。
