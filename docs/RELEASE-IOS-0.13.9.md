# MotoNav iOS v0.13.9

本版新增导入高德「行程报告」分享链接的能力。导航结束后点「分享行程」，或在「我的足迹」里分享走过的路线，把链接粘贴到 App 的「去哪儿」输入框，即可还原这条路线并模拟导航。驾车和摩托车自动识别，无需手动选择。

原有「分享路线」（规划中的路线）链接继续支持，不改变任何已发布行为。固件与 Android 均未改动。

## 问题：行程报告链接被当成无数据网页

高德的两种分享使用不同的跳转页面：

- 路线分享：`surl.amap.com/xxx` 跳到带 `__r=` 或 `shareParam=` 的路线页面，旧版可解析。
- 行程报告：`surl.amap.com/xxx` 跳到 `static3.amap.com/activity/2020NewDriveSafeV5/index.html?urlParameter=…`。这个页面是 Vue 单页，HTML 里没有路线数据，必须拿 `urlParameter` 去后端接口还原。

旧版 `AmapShare` 只认前两种参数，遇到行程报告链接时短链解析失败，报「链接里没有找到路线信息」。这是本次要修的问题，不是链接失效。

## 实现

- `AmapShare.load` 在原有解析失败后检测 `urlParameter`，交给新增的 `loadReport`。
- `m5.amap.com/ws/share/lbs/info` 取起终点和 `naviType`：2 为驾车，9 为摩托车；其余类型按驾车处理。
- `m5.amap.com/ws/share/lbs/route/restoration` 取整条路线：路径点、分段道路、总距离、总耗时和红绿灯数。
- 两个接口的返回转换成与路线分享相同的 `Route` 结构，沿用原有圆屏发图、转向播报和模拟导航路径，不新增固件协议。
- 起终点名称与坐标沿用分享数据；分享数据没有起点时用当前定位。

`loadMotor` / `loadCar` 的路线拼装逻辑抽成 `route(fromPath:)`，路线分享与行程报告共用，避免两套解析逐渐分叉。

## 验证

- 两条真实链接（驾车与摩托车各一条）在 Mac 上用同一解析代码还原成功：起点「我的位置」→ 终点「凌宇(西门)」，约 30 km、2820 秒，路径 636 个点、11 段道路、22 个红绿灯。
- 无签名 Release 构建通过；0.13.9 已签名安装到测试 iPhone 并正常启动。
- 未覆盖：分享数据本身缺失中途点的路线、多段行程折叠分享、高德接口改版。接口与页面均可能随高德调整，解析失败时仍回退为明确错误提示。

## 安装

沿用 0.13.8 的安装方式（Sideloadly 自签），不需要重刷圆屏固件。高德 Key 绑定安装后手机上显示的实际 Bundle ID，详细步骤见 [安装与续签说明](INSTALL-IOS.md)。
