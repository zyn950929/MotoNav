# 1.75 通用固件 7.12.10-pages.5

2026-10-31。基于公开 7.12.10-pages.4，配合 iOS 0.16.0 Build11/12 修正新基础图替换旧建筑图时楼块整片消失的问题。适用于 **微雪 ESP32-S3-Touch-AMOLED-1.75**。

## 修改内容与兼容性

新图收齐、校验并解码后，在现有两个地图缓冲之间按精确世界坐标保留重叠区域已知楼块。只补入地面/绿地区域，新图的道路、水面与新楼块优先；保留数据可以继续传递到下一块，不限于一帧或一次替换。

楼块关闭时同时清除当前及备用缓冲，避免再次出现。坐标系、分辨率、调色板不兼容、非像素对齐或非罪恶都市风格时不合并。每帧 RasterRenderer 与 pages.4 相同，没有新增逐帧采样；没有新增建筑大缓冲或地图蓝牙字节，增加的是收图时的一次合并。

iOS 用 `#BC,1` 显式开启、`#BC,0` 关闭并清理；新连接重新选择是否开启。旧安卓/iOS 客户端不主动启用，原有地图、导航、读秒、时钟、音乐和电源处理协议保留。**本轮未做安卓实机复测**，兼容协议不等于新增保留功能已适配旧安卓。

仅同步 1.75 版本；1.85B 与 M5Stack 不适用这些镜像。公开开机画面为通用 MotoNav/品牌，未加入个人图片。

## 获取、构建和应用升级

本次与 iOS 一并更新源码。此前 pages.4 的 Release 是旧版，不包含本修正。构建方式：

```sh
python3 firmware/build.py
```

依赖 Arduino CLI、ESP32 Arduino Core 3.3.10；Windows 可使用 `firmware/build.ps1 -Board 175` 指定已有环境。输出到 `firmware/dist/175/panel0/`。

已有同板型、相同 16 MB / app3M_fat9M_16MB 分区的 MotoNav，可用 `app_0x10000.bin` 应用升级保留配对和设置；首次完整安装/救砖才使用完整镜像与对应擦除流程。

Windows 独立包生成入口：

```sh
python3 firmware/package_flasher.py --tools-dir /path/to/esptool-files
```

工具目录需包含 esptool.exe 及许可说明。完整解压生成的 ZIP 后运行“一键烧录.bat”，默认选应用升级。`flash.ps1 -VerifyOnly` 仅检查文件与工具，不访问串口。

Mac 下载独立 `macOS-OneClick.zip`，完整解压后双击包内 `一键烧录.command`；镜像和原生工具已包含。详见 [firmware/README.md](../firmware/README.md)。
