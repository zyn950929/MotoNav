# MotoNav iOS 0.14.0

以当前正式包名安卓 8.3.23-webmotor.4 为功能基准，基于本机 iOS 0.13.9 独立开发。安卓、fresh 和固件没有修改。本版由 AI 开发。

## 本轮同步

| 功能 | iOS 实现 |
| --- | --- |
| 五页面 | 首页搜索、圆屏显示、导航语音、圆屏设置、地图 Key；每页独立滚动，巡航在首页靠前 |
| 地图状态 | 首页及圆屏显示页显示取图、传输、离线包状态和错误；失败保留已有底图 |

| 四种地图 | 罪恶都市、原版高德、极简黑白、龙珠雷达；原版直接量化 SDK 默认颜色/标注，黑白独立道路掩码；缓存按风格分离，不套罪恶都市材料 |

## 平台差异及验证范围

- iOS 使用 AVSpeechSynthesizer 系统音色，不提供 Android TTS 引擎或高德安卓原声引擎选择；不读取其他应用的播放器会话和来电号码，也不接听电话。第三方音乐控制沿用圆屏 HID/AMS。
- iOS 后台不能持续进行 SDK GPU 截图。出发前在前台准备沿线地图，锁屏使用已有地图包；不保证锁屏后新地图持续下载。
- WK 持久数据存储保存此设备的网页登录；登录有效期仍由高德决定，过期需重新登录。不会导出账号或 Cookie。
- 网页摩托车接口不是稳定公开 SDK，可能触发登录、安全验证或变更；没有承诺自动绕开所有禁摩区。网页导航没有车道、电子眼或红绿灯秒数。
- 自行车分享的跟随提示以分享分段内容为准，未提供的转向语句不会伪造。自行车重算接口失败时保留原路线并提示。
- GPX 使用原生 WGS84 坐标，高德导航地图使用 GCJ02，两者用途不同。骑行轨迹存储于本机 Documents/Rides，导出才交给系统分享。
- 配套使用已有 1.75 7.12.3/7.12.8 和 1.85B 7.12.3 数据格式。此次没有为这些固件重新发布安装包。
- GitHub Actions 负责 iPhone arm64 Release 编译及计算测试。编译通过不等于已完成 iPhone 安装、定位、联网 Key、登录、锁屏、蓝牙或道路实测。

## 构建、签名和安装

Actions 构建在 `codex/ios-android-parity` 分支，工作流 `iOS Android parity IPA`。产物为 `MotoNav-0.14.0-unsigned.ipa`，含主应用及分享扩展。该 IPA 没有开发者签名，不能直接点击安装。摩友用 Sideloadly 等工具自行签名，并按实际签名后的主应用 Bundle ID 申请高德 **iOS** Key；不用 Android SHA1。免费账号签名有效期及刷新方式以所用工具和 Apple 规则为准。

源码不含 Apple 证书、描述文件、地图/天气 Key 或私人签名。原工程默认 Bundle ID 为 `com.example.motonav`；分享扩展为主 ID 加 `.share`。重签工具必须同时处理扩展。

Mac 本地可在 ios 目录执行 `pod install --deployment` 后打开 `MotoNav.xcworkspace`，选择 Team 和自己的 Bundle ID 进行编译。CocoaPods 依赖由 Podfile.lock 固定。

使用时请遵守交通法规，骑行中勿操作手机。使用本套程序视为自愿承担可能带来的交通事故风险。
