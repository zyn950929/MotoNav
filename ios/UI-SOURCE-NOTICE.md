# 界面来源

本次在 MotoNav iOS 0.16.0 基础上，移植并适配 coolcoolmanman-design/MotoNav 的 0.15.21-tpms 界面。
参考提交：https://github.com/coolcoolmanman-design/MotoNav/tree/c01d6db1a323e91d0b0210b796d9bb6a0cd7bd0f

参考内容：四栏目结构、语义配色、玻璃导航栏、设备卡、圆屏连接动效和轨迹页面。
功能仍以本项目 0.16.0 为基础；未移植胎压、音乐封面或对方固件协议扩展。界面不提供调试信息和测试帧入口。
项目沿用随附的非商业条款，第三方地图保留来源标注，AI 辅助开发说明保留。
